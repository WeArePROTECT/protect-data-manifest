# Feedback inbox

New reports land here — **one file per report**, named `<YYYY-MM-DD>_<short-slug>.md`.

- **Reporting something?** See [`../REPORTING.md`](../REPORTING.md) (point your Claude agent at it).

Reports here are drafts pending review — filing one does **not** change the catalog. Spencer verifies
each against the real data before anything is applied.
